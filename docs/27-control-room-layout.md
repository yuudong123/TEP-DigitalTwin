# 단일 화면 관제 레이아웃 — 2026-10-15

## 배치와 표시

- 화면 전체를 고정 그리드로 사용한다. 상단 왼쪽부터 공정 전체 상태, 잔여수명, 1/2/4시간 위험도를 표시한다.
- 중앙은 공정 흐름 모형, 오른쪽은 상위 위험 요인과 운전상태 변화, 하단은 재생 제어다.
- Unity 공정 화면과 같은 어두운 배경·청록 강조·나눔고딕을 웹에 적용한다. 폰트 라이선스를 함께 배포한다.
- WebGL의 중복 HUD는 숨기고 카메라가 전체 캔버스를 사용한다. 독립 실행 HUD는 보존한다.
- 상태 밴드는 공정 전체 판정이며 설비별 고장 위치를 뜻하지 않는다. 갱신이 지연되면 마지막 공정 판정으로 구분한다.
- 최소 지원 표시 영역은 1000×720 CSS px다. 이보다 작으면 창 크기 안내를 표시한다.
- 런타임 생성 원통의 CapsuleCollider가 WebGL stripping에서 사라지지 않도록 link.xml에 명시한다.

## 이번 변경의 실제 검증

- 운영 주소 `http://tep-server:8000/`에서 새 빌드를 직접 확인했다.
- 1000×720, 1280×720, 1366×768, 1920×1080에서 페이지 스크롤과 검사 대상 패널/위험 요인 행의 넘침이 없었다. 최소 폭 화면도 캡처로 확인했다.
- 실제 시나리오 1 재생을 시작해 API 예측과 컴파일된 Unity ACK가 갱신되는 것을 확인했다. ACK의 source trajectory는 case1::1, connection은 connected였다.
- 브라우저 콘솔 error 0건, Unity ready, 재생 264행 전송 후 소유한 재생만 중지했다. 서비스를 종료하거나 데이터를 삭제하지 않았다.
- Python 112개, 웹 6개 테스트, lint, TypeScript/운영 빌드, 네 서비스 배포 확인을 통과했다.
